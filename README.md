# Xandão Streaming — Marvel Edition

Projeto de estudo em HTML, CSS e JavaScript puro.

## Abrir no VS Code
1. Extraia `xandao-steaming-marvel.zip` na Área de Trabalho.
2. Abra o VS Code → **Arquivo > Abrir Pasta...** → escolha `xandao-steaming`.
3. Abra `index.html`.
4. Recomendado: instale a extensão **Live Server** e use **Open with Live Server**.

## Funcionalidades
- Catálogo dividido por filmes Marvel, séries Marvel, Top 10 Brasil de séries, Top 10 Brasil de filmes e lançamentos.
- Busca por título.
- Janela de informações ao clicar em um título.
- Minha lista: o botão + adiciona e remove títulos, atualiza os cards e salva a lista no navegador mesmo após atualizar a página.
- Seletor de perfis e criação de perfis com avatares inspirados em personagens.
- Interface responsiva para computador e celular.

## Sobre as capas e marcas
As capas disponíveis usam caminhos do CDN público do TMDB. Nem todas as capas de séries e lançamentos têm uma imagem confirmada neste protótipo; quando não há imagem configurada, aparece uma arte de reserva. As listas Top Brasil e lançamentos foram organizadas conforme os dados fornecidos e podem precisar de conferência editorial. O projeto é uma demonstração, não reproduz vídeos e não é afiliado à Marvel, Disney ou a qualquer serviço de streaming.
